🔧 BW Brand Issues - Diagnostic & Fixes

Complete guide for resolving logo preview and description saving issues

📋 What Was Wrong

  • Logo preview shows "No logo yet" in admin even though logo displays on public site
  • Descriptions not saving to admin field or not showing on public site
  • Logo could be lost when updating brand description without uploading new image

✅ Fixes Applied

  • Logo Preservation: Database now preserves existing logo better when updating descriptions
  • Fallback Display: Admin now shows fallback logo from assets/brands/ if no custom logo
  • User Feedback: Admin shows whether logo is from fallback or custom upload

🧪 Testing the Fix

Step 1: Check Admin Preview Navigate to: /ANDISON/Andison/admin/products.php?brand=BW
  • Click "Edit Brand" button
  • Look at "Brand Image Preview" section
  • You should now see the BW logo ✓
  • It should show: "⚠ Fallback logo - Using default image"
Step 2: Test Description Save
  • In the admin edit form, edit the brand description
  • Add a test sentence like: "Updated on [today's date]"
  • Click "Save Brand"
  • Refresh the page (F5)
  • Check if your text is still there
  • Go to public site: /brand.php?name=BW
  • Scroll down to find the brand description
  • It should show your updated text
Step 3: Upload Custom Logo (Optional)
  • In admin edit form, click "Choose File" under "New Brand Image"
  • Select a custom BW logo file
  • Preview should update with your image
  • Click "Save Brand"
  • After save, it should show: "✓ Custom logo from admin data"

💡 How It Works Now

Admin Preview Logic:

  1. Check if BW has custom logo in database → Show it with ✓ indicator
  2. If no custom logo, check for fallback file → Show it with ⚠ indicator
  3. If both missing → Show "No logo yet"

Public Site Logic:

  1. Check if BW has custom logo in database → Use it
  2. If not, use fallback from assets/brands/ → Show public logo

Result: Admin and public site now show the same logo!
